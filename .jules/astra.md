\n## 2025-02-27 - Validating Gemini JSON responses\n**Learning:** When using JSON.parse() on responses from Gemini (or any LLM), technically valid JSON can silently bypass the catch block fallback logic. If critical structured fields (like an expected array of `questions`) are missing, the UI will crash down the line.\n**Action:** Always validate the structure of the JSON object immediately after JSON.parse() and throw a descriptive error if the contract is missing. This ensures the catch block reliably intercepts unexpected model output and provides the configured fallback.
